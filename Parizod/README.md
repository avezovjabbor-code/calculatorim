# 🌸 Parizod - Zamonaviy va Nafis Web Kalkulyator

**Parizod** — zamonaviy dizayn, boy imkoniyatlar va yuqori darajadagi qulaylik bilan yaratilgan aqlli kalkulyator dasturi.

## ✨ Asosiy Imkoniyatlar:
1. **Oddiy va Standart hisob-kitoblar**: qo'shish, ayirish, ko'paytirish, bo'lish, foiz (%), daraja (^).
2. **Muhandislik (Scientific) Rejimi**:
   - Trigonometrik funksiyalar: sin, cos, 	an (Gradus - DEG va Radian - RAD rejimlarida)
   - Matematik konstantalar: π (Pi), e (Eyler soni)
   - Logarifmlar: log (o'nlik logarifm), ln (natural logarifm)
   - Ildiz va darajalar: √, x², xʸ, 1/x, 
! (faktorial)
   - Qavslar bilan murakkab ifodalarni hisoblash
3. **Aqlli Konverter**:
   - Valyuta kurslari (UZS, USD, EUR, RUB, TRY, CNY)
   - Uzunlik birliklari (metr, santimetr, kilometr, dyuym, fut)
   - Og'irlik birliklari (kg, gramm, tonna, funt)
   - Harorat o'lchovlari (Selsiy °C, Farengeyt °F, Kelvin K)
4. **4 ta Maxsus Chiroyli Mavzular (Themes)**:
   - 🌸 **Parizod (Pushti / Oltin)** - Nafis va jozibador
   - 🌌 **Tungi Kosmos (Qora / Neon)** - OLED qora va kiberpank yorug'lik
   - ✨ **Zumrad (Yashil / Oltin)** - Hashamatli zumrad jilosi
   - 🌅 **Qizil Shafaq (Binafsha / Olov)** - Yorqin g'urub ranglari
5. **Tovush effektlari (Web Audio API)**:
   - Klaviaturada bosish ovozlari va muvaffaqiyatli hisoblash musiqiy signali (yoqish/o'chirish imkoniyati bilan)
6. **Hisob-kitoblar Tarixi (History)**:
   - Avvalgi barcha amallarni saqlash, qayta yuklash va tozalash
7. **Xotira amallari (Memory)**:
   - MC, MR, M+, M-, MS
8. **To'liq klaviatura boshqaruvi**:
   - Raqamlar, Enter (=), Backspace (o'chirish), Escape (tozalash)
